# tokens

层级：L1 token。代码入口：`code.css`。

这个对象不是散落 CSS 文件，而是一个可以被阅读、校验、扩展的模块。

## 说明

ZE Design Tokens — 「精密瓷釉 Precision Porcelain」(v4)
晴空瓷釉的精密化修订:同一气质(玻璃面板 / 冷调乳灰 / 通电 accent),但更精密、清晰、简洁、有逻辑。
与 v3 的差异(MAJOR):
1. 系统色全手工设计 —— 表面6 + 墨5 + 线3 + 语义8 + 数据8,每色一个固定职责;
强调组是「主题色插槽」:36 个工具主题色在 01-tokens/themes.css(每工具占一色,
规范全同、仅主题色不同);wash/tint/glow 由 accent-500 相对色派生,换主题自动跟随。

## 对外表面

无 `.ze-*` class；该对象提供令牌、生成物或文档事实。
