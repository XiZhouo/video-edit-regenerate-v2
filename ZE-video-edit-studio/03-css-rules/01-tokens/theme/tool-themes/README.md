# tool-themes

层级：L1 token。代码入口：`code.css`。

这个对象不是散落 CSS 文件，而是一个可以被阅读、校验、扩展的模块。

## 说明

themes.css — ZE 工具主题色 ×36(01-tokens)
「每个工具遵守同一套规范,只有主题色不同。」
本文件 = 36 个全手工设计的工具主题色。每个主题给 4 个设计值(500 主色 / 700 按下 /
200 浅块 / soft 大面积浅底),light + dark 各一组 —— 不是公式推导:L/C 按色相区手工锁定
(红区收明度、黄区提明度降彩度、蓝紫区提彩度),保证任意主题下主按钮反白字对比 ≥4.5:1、
明暗一致的"通电感"。

## 对外表面

无 `.ze-*` class；该对象提供令牌、生成物或文档事实。
